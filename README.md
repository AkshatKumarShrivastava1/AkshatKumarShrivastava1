## 🚀 How to run my projects (Quick Start)

```bash
# Clone repo
git clone https://github.com/AkshatKumarShrivastava1/QuickGpt-AI-Powered-Project.git

# ---------- FRONTEND ----------
cd QuickGpt-AI-Powered-Project/client
npm install
# 🔑 Setup environment: REACT_APP_API_URL=<Backend_URL>
npm run dev  # 🌐 Starts frontend on http://localhost:5173

# ---------- BACKEND ----------
cd ../server
npm install
# 🔑 Setup environment:
# MONGO_URI=<Your MongoDB URL>
# JWT_SECRET=<Your Secret Key>
# STRIPE_SECRET_KEY=<Your Stripe Key>
# OPENAI_KEY=<Your OpenAI API Key>
# TWILIO_* = <Your Twilio Account SID & Auth Token>
npm run dev  # 🌐 Starts backend on http://localhost:5000
